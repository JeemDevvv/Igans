# IPO Model for Igan's Budbod House Food Ordering System

## Input
These are the data and resources that enter the system:
1. **User Inputs**
   - User credentials (username, password) for login/registration
   - User information (full name, email) for account creation
   - Username for password recovery
   - OTP code for password reset verification
   - New password for password reset
2. **Admin Inputs**
   - Menu item details (name, description, category, price, image URL, nutrition info, availability status)
   - Category details for menu organization
   - User account management actions (add/edit/delete users)
3. **Customer Inputs**
   - Menu item selections for orders
   - Quantity adjustments for cart items
   - Order type selection (dine-in, take-out, delivery)
   - Table number (for dine-in)
4. **System Resources**
   - MongoDB database connection
   - SMTP server for email sending
   - Node.js backend server
   - Frontend HTML/CSS/JS files

---

## Process
These are the actions the system performs with the inputs:
1. **Authentication & Authorization**
   - Validate user credentials during login using bcrypt password comparison
   - Generate and verify JWT tokens for secure sessions
   - Check user roles to restrict access to protected routes
2. **User Account Management**
   - Hash user passwords with bcrypt during registration
   - Store user accounts in MongoDB
   - Generate and send OTP codes via email for password recovery
   - Verify OTP codes and update user passwords
3. **Menu Management**
   - Create, read, update, and delete menu items in MongoDB
   - Organize menu items by categories
   - Filter and search menu items based on user input
4. **Cart & Order Management**
   - Add, remove, and update items in the customer's cart
   - Calculate order total prices
   - Create and store orders in MongoDB
   - Update order statuses (pending, preparing, ready, delivered)
5. **System Administration**
   - Load and display admin dashboard data
   - Manage restaurant settings
   - Track orders and generate reports

---

## Output
These are the results and outputs generated by the system:
1. **Authentication Outputs**
   - JWT tokens for authenticated sessions
   - Success/error messages for login/registration
   - Dashboard redirection based on user role
2. **User Account Outputs**
   - OTP codes sent to user email
   - Password reset success/error messages
3. **Menu Outputs**
   - Filtered and searched menu item lists
   - Menu detail pages with nutrition information
4. **Cart & Order Outputs**
   - Updated cart displays with total prices
   - Order confirmation notifications
   - Order status updates for customers
5. **Admin Outputs**
   - Admin dashboard with order statistics
   - Order management interface
   - Menu management interface
   - User account management interface
6. **Customer Outputs**
   - User-friendly menu interface
   - Cart and checkout pages
   - Order status tracking page
